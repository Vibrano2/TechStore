# Design System

## Design Direction
Clean, premium, modern German electronics retail experience.

Avoid:
- Marketplace clutter
- Excessive gradients
- Oversized promotional banners
- Too many colors
- Low-contrast text

## Core Palette
### Primary
- Deep Navy: `#0B1F33`
- Electric Blue: `#0F5BD8`

### Neutral
- White: `#FFFFFF`
- Background: `#F6F8FB`
- Border: `#E3E8EF`
- Text Primary: `#111827`
- Text Secondary: `#667085`

### Status
- Success: `#15803D`
- Warning: `#D97706`
- Error: `#DC2626`

## Typography
Recommended:
- Inter
- Geist
- Manrope

### Scale
- Display: 48-64px
- H1: 40-48px
- H2: 30-36px
- H3: 22-28px
- Body: 16px
- Small: 14px
- Caption: 12px

## Layout
- Max content width: 1440px
- Desktop gutter: 32px
- Tablet gutter: 24px
- Mobile gutter: 16px

## Radius
- Small: 6px
- Default: 10px
- Card: 14px
- Large: 20px

## Buttons
### Primary
Blue background, white text.

### Secondary
White background, navy border.

### Destructive
Red background or red text depending on context.

## Product Cards
Include:
- 1:1 product image area
- Brand
- Product name
- Rating
- Price
- Old price if discounted
- Stock status
- Wishlist icon
- Add to cart CTA

## Imagery
Use clean product photography on neutral backgrounds.

E-mobility lifestyle imagery should feel realistic and German-market appropriate.

## Icons
Use one consistent outline icon set across the product.

Recommended:
- Lucide
- Heroicons

## Navigation
Desktop:
- Main header
- Search
- Category nav

Mobile:
- Header with search
- Bottom navigation:
  - Start
  - Kategorien
  - Favoriten
  - Warenkorb
  - Konto

## Accessibility
- WCAG AA contrast
- Keyboard navigation
- Visible focus states
- Proper labels
- 44px minimum tap targets on mobile
- Semantic HTML
- Alt text for meaningful images
